이번 버전 핵심
- PC/휴대폰/가로모드/폴더블/태블릿 반응형
- 날짜: 위 ▲ 전날 / 가운데 양력+음력+▼ / 아래 ▼ 다음날
- 날짜 ▼: 년/월/일 3열 룰렛형 스크롤 선택
- 날씨표: 좌측 항목 고정, 우측 시간대만 가로 스와이프
- 시간: 0 / 3 / 6 / 9 / 12 / 15 / 18 / 21
- 강수: 비가 있을 때만 숫자, 없으면 빈칸
- 바람/돌풍: 셀에는 숫자만, 단위는 좌측 라벨에 표시
- 풍향: 화살표만 표시
- 파고: 셀에는 숫자만, 단위는 좌측 라벨에 표시

GitHub 업로드
1. 압축을 풉니다.
2. 현재 폴더 안의 파일과 폴더를 ficamx.github.io 저장소 root에 전체 업로드합니다.
3. Commit changes 합니다.
4. PC에서 예전 화면이면 https://ficamx.github.io/?v=8 로 한 번 접속합니다.

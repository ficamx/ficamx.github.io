휴대폰 홈 화면 설치
1) 이 폴더를 HTTPS 웹호스팅(Netlify / Cloudflare Pages / GitHub Pages 등)에 올립니다.
2) 휴대폰에서 해당 주소를 엽니다.
3) Android Chrome: 메뉴(⋮) > 앱 설치 또는 홈 화면에 추가
4) iPhone Safari: 공유(□↑) > 홈 화면에 추가
